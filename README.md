# Virtual Temple

An online Buddhist virtual temple for a Malaysian audience. See [AGENTS.md](AGENTS.md) for commands and conventions, and [docs/mvp/](docs/mvp/) for the intent, spec and plan.

```bash
pnpm install
pnpm dev     # http://localhost:5173/?hall=1 in two tabs (needs no Cloudflare account); add &debug=1&stress=50 for a frame-rate check
pnpm test
```
